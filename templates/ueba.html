Baseline Model Parameters

The model compares today's event volume against this entity's historical same weekday (e.g. today's Friday count vs. its past Fridays), using median and MAD (median absolute deviation) instead of mean/stddev so a single past spike day doesn't drag the baseline up for weeks. An entity is flagged when today exceeds baseline median + (multiplier × MAD-derived spread), and only once its baseline clears the minimum floor. Both entity types share these settings.

Below this, falls back to a flat baseline across all weekdays until enough same-weekday history builds up.
