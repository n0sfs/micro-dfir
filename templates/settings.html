Database Maintenance & Backups

Manage local SQLite database health and generate manual backups.

Log Retention

Choose how long ingested logs are kept. Retention needs vary by policy, industry, and jurisdiction — pick the period that matches your own compliance requirements; these are common reference points, not a recommendation.

Log Archiving

Move logs older than the archive window out of the live search index into cold storage in the same database, so Log Search stays fast without losing older data outright. Independent of Log Retention above -- if both are enabled, keep the retention period longer than the archive window, or retention will purge logs before they get a chance to be archived.

Database Backups

Nightly consistent snapshots of the full database (SQLite's own safe-copy mechanism, not a plain file copy, so it can run against a live, actively-written database without risk of a torn/corrupted copy). Restoring from a backup needs SSH access to the server and stops services briefly to swap the database file -- see restore_db.sh in the repo root for the documented procedure; it isn't offered as a button here for that reason.
