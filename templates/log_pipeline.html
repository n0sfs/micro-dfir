Log Source Silent Alert

Distinct from a log source that has never ingested anything at all (see Coverage) -- this flags a source that WAS recently active and then stopped, the "pipeline broke" case. The threshold adapts per log source from its own recent history (multiples of its typical time between events), so a naturally continuous source and a naturally bursty one don't need separate hand-tuned thresholds.

DNS Query Logging

Point a specific device's own DNS setting at this appliance's IP to opt it in; nothing here changes automatically for the rest of the network. Read-only: this panel shows status and the exact parser in use, but editing the parser or dnsmasq's own config is not done from the UI.

Linux Log Channels

System journal (syslog, auth, kernel, every systemd unit) is always collected in full -- journald has no equivalent of a Windows "channel" to selectively filter. The real gap on Linux is process-execution and sensitive-file-change visibility, which the kernel doesn't surface at all without auditd rules loaded. Enabling a channel below both installs the required auditd rule on the endpoint (the "push" half) and starts pulling its specific audit log entries (the "pull" half) -- toggling it off removes the rule again. Requires auditd to be installed on the endpoint; hosts without it are silently skipped, not errored.
