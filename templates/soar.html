Playbooks run automatically -- when a case is created (or its status, queue, or assignee changes), when a new alert fires, or on a schedule. Scope a playbook to a specific queue, TLP, status, or severity, then chain together actions (apply a case template, add a task/note, set queue, run host/user analysis, email/webhook/ Slack, or an EDR response) that run in order every time it fires. Any case-scoped action can be flagged "Requires approval" -- instead of running immediately, it's queued below until someone approves or rejects it. Use "Run Now" on a playbook to fire it on demand against a specific case, instead of waiting for its trigger.
