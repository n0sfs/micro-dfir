SOC Secret Token (Ingestion API)

Used by Vector and deployed log forwarders to authenticate against the ingestion API.

Download pre-configured agent scripts embedded with your current SOC secret and server IP, or manage local background services.

Windows -- Installer Recommended
Download Installer (.zip)

Bundles its own Python runtime -- no separate Python install needed on the endpoint. Extract the .zip (keep agent_config.json next to the .exe) and double-click MicroDFIRAgentSetup.exe; it will prompt for administrator approval, install itself to C:\Program Files\MicroDFIR, and register the background service automatically. An uninstaller is added to Windows' "Add or Remove Programs" list.

Windows -- Plain Script Advanced
Download Agent (.zip)

Requires Python 3.10+ already installed on the endpoint (check "Add python.exe to PATH" during install) -- this is a plain script, not a bundled .exe. If `python` isn't recognized after installing, open a new terminal window (PATH changes don't apply to one already open). Prefer the Installer above unless you specifically need the raw script (e.g. to read/modify it before running).

To run the agent persistently in the background, open PowerShell as Administrator and run:

python micro_agent_windows.py install

To stop and remove the background service:

python micro_agent_windows.py uninstall
Linux
Download Agent (.tar.gz)

To run the agent persistently as a systemd service, extract the download and run as root:

sudo python3 micro_agent_linux.py install

To stop and remove the background service:

sudo python3 micro_agent_linux.py uninstall
macOS
Download Agent (.tar.gz)

To run the agent persistently as a launchd daemon, extract the download and run as root (launchd requires it for a system-level daemon):

sudo python3 micro_agent_macos.py install

To stop and remove the background service:

sudo python3 micro_agent_macos.py uninstall

macOS support is newer and has a smaller action set than Windows/Linux (no persistence sweep, software inventory, or SCA checks yet), and host isolation (pfctl) has not been live-verified against real macOS hardware -- test Isolate Host on a non-critical machine before relying on it during a real incident.

Already-deployed agents can also be upgraded remotely from the Response Actions tab instead of reinstalling by hand.
