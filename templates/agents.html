Windows Background Service Management

To run the Windows agent persistently in the background, open PowerShell as Administrator and run:

python micro_agent_windows.py install

To stop and remove the background service:

python micro_agent_windows.py uninstall

Already-deployed agents can also be upgraded remotely from the Response Actions tab instead of reinstalling by hand.
